# 中文版数字时钟

这是一个无需构建工具的多时区数字时钟页面，支持实时刷新、时区搜索、添加/移除时钟、深浅色模式和本地保存配置。

## 使用方式

直接用浏览器打开 `frontend/clock/index.html`，或在仓库根目录启动一个静态服务器：

```bash
python -m http.server 8080
```

然后访问 <http://localhost:8080/frontend/clock/>。

## 功能

- 北京、东京、伦敦、纽约等多个时区实时显示
- 每秒刷新当前时间和日期
- 按城市、国家或 IANA 时区搜索
- 自定义添加和移除时区
- 使用 `localStorage` 保存个人时钟配置
- 响应式布局，支持移动端
- 深色/浅色主题切换
